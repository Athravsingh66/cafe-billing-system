# ☕ The Coffee Corner - Cafe Billing System

A simple **console-based Cafe Billing System built with Python**.

This project was created to practice Python fundamentals such as dictionaries, nested dictionaries, lists, loops, conditional statements, functions, user input, and basic billing calculations.

## 📌 Features

* Display cafe menu
* View item price and category
* Place customer orders
* Store ordered items in a cart
* Calculate the total bill
* Simple console-based interface
* Input validation for unavailable items

---

## 📂 Project Versions

This repository contains two versions of the project.

### 🟢 Version 1 - Basic Cafe Billing System

The first version focuses on implementing the basic functionality of a cafe billing system.

### Features

* Menu stored using a nested dictionary
* Display menu to the customer
* Customer can add multiple items
* Items are stored in a list
* Show customer cart
* Calculate total bill
* Main menu for navigation

### Python Concepts Used

* Dictionary
* Nested Dictionary
* List
* `for` loop
* `while` loop
* `if-elif-else`
* Functions
* `input()`
* Dictionary access

---

### 🔵 Version 2 - Improved Cafe Billing System

Version 2 improves the original system by introducing a better cart structure and additional functionality.

### Improvements

* Quantity support
* Dictionary-based shopping cart
* Duplicate items are combined automatically
* Better cart display
* Remove items from cart
* Input validation
* Empty-cart handling
* GST calculation
* Discount coupon system
* CAFE10 gives 10% discount
* CAFE20 gives 20% discount
* Invalid coupon codes are handled
* Customer can skip the coupon
* Improved bill formatting
* Cleaner program structure

### Example

```text
Espresso        ₹120 × 3 = ₹360
French Fries    ₹90  × 2 = ₹180

Subtotal:       ₹540
GST (5%):       ₹27
Grand Total:    ₹567
```
